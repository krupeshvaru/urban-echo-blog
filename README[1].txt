URBAN ECHO — BLOG WEBSITE
==========================
A modern editorial-style blog website made with HTML, CSS and JavaScript.

FILES
-----
index.html  - Main webpage
style.css   - Design and responsive layout
script.js   - Search, filters, modal stories, menu and newsletter interaction

FEATURES
--------
- 5 original blog stories
- Search
- Category filters
- Read-story popup
- Responsive mobile design
- Mobile navigation
- Newsletter interaction
- About and philosophy section
- GitHub Pages ready

GITHUB PAGES
------------
Upload all four files to a GitHub repository.
Go to Settings > Pages > Deploy from a branch > main > /(root) > Save.
